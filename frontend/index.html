THE PROBLEM

Why public benchmarks can mislead

📊

Public benchmarks are public

The ARC-AGI-1 evaluation set has been publicly available since 2019. It appears in web-scraped training corpora. A model's score on it may reflect familiarity, not just fresh rule induction.

🔄

Distribution matching

We generate fresh tasks whose measurable properties — grid size, color count, training pair count — match the public distribution. This makes scores comparable while removing familiarity as a confound.

⚖️

The gap is the signal

If a solver scores higher on public tasks than on fresh ones, the difference is a diagnostic signal — consistent with familiarity, but also with distribution mismatch, generator artifacts, or difficulty shifts.

Scientific caution: A performance gap does NOT prove memorization. It provides a diagnostic signal consistent with multiple explanations including benchmark familiarity, task-distribution mismatch, generator artifacts, task ambiguity, and solver limitations.

METHODOLOGY

How fresh tasks are generated

The pathwaycom/arc-task-gen pipeline generates distribution-matched ARC tasks through a multi-stage process.

1

Distribution Analysis

Measure the public ARC-AGI-1 evaluation set: grid dimensions, color counts, training pair counts.

↓
2

Joint Constraint Sampling

Sample a complete slot from a single real eval task, preserving natural covariance between grid size, colour count, and pair counts.

↓
3

LLM Task Generation

An LLM invents a genuinely new transformation rule matching the sampled constraints. One task per call.

↓
4

Structural Validation

Verify: valid 2D grids, cell values 0–9, no ragged rows, minimum training pairs.

↓
5

Semantic Deduplication

Embed rule descriptions; remove generated tasks too similar to each other (cosine > 0.80).

↓
6

Public-Eval Similarity Filter

Remove tasks whose rule description is too close to any official eval task (cosine > 0.92).

↓
✓

Fresh Private Task Set

Distribution-matched, structurally valid, semantically novel tasks ready for evaluation.

Important limitation: Solvability is not verified programmatically. A generated task passes structural validation but may have an ambiguous or uninferrable rule. This is why a blind human audit is valuable.

REASONING & RECURRENT MEMORY

BDH-CQ: Contextual Demonstration Adaptation

EXPLICIT LEARNING OBJECTIVE

After this interaction, you should be able to explain how BDH-CQ can incorporate demonstration information through contextual/recurrent associative state without performing parameter updates or backpropagation on the evaluation task.

Architecture & Adaptation Mechanism

BDH-CQ is built on Dragon Hatchling (BDH), a recurrent architecture where units communicate through low-rank interactions and maintain context in an evolving associative memory matrix. At test time, BDH-CQ processes task demonstrations by updating its recurrent latent state, solving queries through iterative internal recurrent computation — without parameter fine-tuning and without external scratchpads.

Conceptual State Update Equation Conceptual Teaching Abstraction

$$S_{t+1} = \alpha S_t + (1 - \alpha) \cdot \Big(\phi(x_t) \otimes \psi(y_t)\Big)$$ $$\hat{y}_{\text{test}} = \operatorname{Readout}\Big(S_{T}, \phi(x_{\text{test}})\Big)$$

Notice: Model weights $W$ remain fixed ($\nabla_W \mathcal{L} = 0$). Only the transient recurrent associative state $S \in \mathbb{R}^{D \times D}$ evolves as demonstrations $(x_t, y_t)$ are streamed into context.

Toy Model Simplification Specification

Each ARC grid is encoded via an invariant feature projector $\phi(x) \in \mathbb{R}^4$ capturing color histogram and positional center-of-mass moments. The associative state matrix $S$ acts as a linear associative memory accumulating outer-product bindings $\phi(x_t) \psi(y_t)^T$. The readout computes $\hat{y} = \operatorname{Decode}(S^T \phi(x_{\text{test}}))$. This illustrates the computational power and failure modes of associative recurrent accumulation without replicating BDH-CQ's full multi-head low-rank recurrent layers.

Adaptation Paradigm Comparison

⚙️

Optimization-Based Test-Time Adaptation (e.g. HRM / TRM)

Demonstrations $\to$ Task Loss $\to$ Backward Pass $\to$ Parameter / Embedding Updates $\Delta W$ $\to$ Prediction

  • Mechanism: Modifies actual model weights or task-specific identity embeddings at evaluation time via gradient optimization.
  • Compute Profile: Requires backpropagation and gradient descent per test instance; high latency and compute overhead.
  • Trade-off: High task-specific expressivity, but prone to overfitting on sparse examples and computationally expensive.
🧠

Contextual / Recurrent Adaptation (Illustrated by BDH-CQ)

Demonstrations $\to$ Recurrent State Accumulation $S_{t+1} = f(S_t, x_t, y_t)$ $\to$ Latent Readout $\to$ Prediction

  • Mechanism: Model weights remain strictly frozen ($W_{\text{fixed}}$); task rules reside entirely in transient associative state.
  • Compute Profile: Purely forward inference pass; orders of magnitude cheaper ($0.0007 per task) with rapid latency.
  • Trade-off: Bounded memory capacity; rule induction fidelity depends entirely on context-state binding dynamics.

Why ARC & Fresh Generalization Are Critical Here

ARC is an ideal testbed for recurrent contextual adaptation because each problem provides only 2 to 5 sparse demonstrations. The solver cannot rely on statistical memorization; it must bind and execute an unseen transformation solely through in-context dynamics.

Connection to Our Central Claim

Whether a recurrent reasoning system succeeds on a familiar public task and whether it can infer an arbitrary rule from an unseen task are related but distinct questions.

"A model's performance on a public ARC benchmark can differ from its performance on novel tasks matched on observable benchmark properties; therefore, public benchmark accuracy alone cannot establish generalization."

Evaluating models like BDH-CQ on distribution-matched fresh tasks generated by arc-task-gen ensures that high few-shot scores reflect true contextual rule induction rather than implicit benchmark familiarity.

Scientific Scope: Fresh-task evaluation provides a diagnostic instrument. While BDH-CQ's recurrent associative state is conceptually distinct from parametric memorization, benchmark accuracy alone cannot completely rule out inductive distribution bias.
RIGOR

Methodology & Limitations

What this experiment can show

  • Whether a solver's accuracy differs between public and fresh tasks
  • Which task properties correlate with failure
  • Whether distribution matching produces comparable task sets
  • The magnitude of any public-to-fresh performance gap

What this experiment cannot prove

  • That a model has memorized specific ARC tasks
  • That generated tasks are perfectly equivalent to public ones
  • That all generated tasks are unambiguously solvable
  • That the gap is entirely due to a single cause

Known Limitations

Generated task solvability

Structural validation does not guarantee that a generated task has an unambiguous, human-inferable rule. A blind human audit addresses this partially but not completely.

Distribution matching is partial

Tasks are matched on measurable properties (grid size, colors, pair count) but may differ in unmeasured ways (cognitive complexity, rule novelty, visual salience).

Generator artifacts

LLM-generated tasks may have systematic biases: preference for certain transformation types, difficulty levels, or grid patterns.

Small sample sizes

With small generated sets, confidence intervals are wide and results should be interpreted as exploratory, not definitive.

2. Recurrent Associative Latent Reasoning (BDH-CQ)

Engdahl et al. (2026) — BDH-CQ: Introducing In-Context Learning with Recurrent Latent Reasoning (arXiv:2608.09888).

Introduces the 150M parameter Dragon Hatchling (BDH-CQ) architecture combining continuous latent reasoning and recurrent associative state adaptation, reporting 29.5% pass@2 on public ARC-AGI-1 at $0.0007 per task without test-time backpropagation or parameter updates ($\nabla_W \mathcal{L} = 0$).

3. Test-Time Optimization vs. Contextual Inference

Akyürek, Damani, Qiu, Guo, Kim, & Andreas (2024) — The Surprising Effectiveness of Test-Time Training for Abstract Reasoning (arXiv:2411.07279).

Investigates test-time training (TTT) on ARC, serving as the empirical exemplar of optimization-based test-time parameter adaptation that contrasts with forward-pass non-parametric recurrent memory accumulation (as featured in BDH-CQ).
