# AI Disclosure

## Overview

This project was developed with AI assistance. This document transparently describes what AI tools contributed and where human judgment was applied.

## AI-Assisted Components

### Coding
- **Tool**: AI coding assistant (Antigravity/Gemini)
- **Scope**: Project architecture, backend API implementation, frontend interactive components, CSS design system
- **Human review**: All generated code was reviewed, tested, and iterated. Architecture decisions were human-directed.

### Research Assistance
- **Tool**: AI coding assistant
- **Scope**: Reading and analyzing the upstream `pathwaycom/arc-task-gen` repository, understanding the ARC-AGI evaluation methodology, synthesizing the research question
- **Human review**: All factual claims were verified against primary sources (the upstream README, source code, and published results)

### Documentation
- **Tool**: AI coding assistant
- **Scope**: README, concept summary, methodology, provenance documentation
- **Human review**: All documentation was reviewed for accuracy and completeness

### Generated Content
- **Demo tasks**: The 5 hand-crafted demo ARC tasks in `data/demo/` were created by the AI assistant and verified for correctness by testing them against the validation logic
- **Interface text**: Educational explanations, caution boxes, and methodology descriptions

## What AI Did NOT Do

- **Reproduce BDH-CQ results**: All BDH-CQ performance figures are cited from published sources, clearly labeled as PUBLISHED
- **Generate experimental results**: All experimental measurements are computed in real-time by the evaluation pipeline
- **Run the arc-task-gen pipeline**: No tasks were generated by the LLM task generator during development
- **Fabricate data**: No benchmark results, solver accuracies, or statistical significance values were invented

## Human Contributions

- Research direction and problem framing
- Architecture decisions and design review
- Scientific accuracy review (especially limitations and caution language)
- Testing and verification
- Final editorial judgment on all user-facing content

## Verification Process

All factual claims in the project were verified against:
1. The `pathwaycom/arc-task-gen` source code and README (read directly from GitHub)
2. The ARC-AGI repository and ARC Prize documentation
3. The upstream `instructions.md` for pipeline behaviour
4. Published BDH-CQ results from the arc-task-gen README
